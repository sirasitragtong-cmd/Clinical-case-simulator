# ทีม AI สำหรับพัฒนา PharmVille

ผู้ใช้เป็นผู้กำหนดเป้าหมายและทิศทาง ส่วน AI ผู้ประสานงานหลักเป็นจุดติดต่อเดียว: รับคำสั่ง แบ่งงาน ติดตาม รวมโค้ด ตรวจผล และส่งงานกลับให้ผู้ใช้

## ฝ่ายที่ใช้ทำงาน

| ฝ่าย | งานที่รับผิดชอบ | ตัวอย่าง |
| --- | --- | --- |
| ผู้ประสานงานและสถาปัตยกรรม | แปลงคำสั่งเป็นงาน กำหนดขอบเขต เชื่อมส่วนต่าง ๆ และเผยแพร่ | เพิ่มระบบคิวโดยไม่ทำให้ SOAP หรือระบบเดิมเสีย |
| ออกแบบ UX/UI | หน้าตา ตำแหน่งปุ่ม ภาษา การใช้งานบนขนาดจอต่าง ๆ และการเข้าถึง | ขยายฉาก จัดแถบเครื่องมือ ปรับหน้าจอมือถือ |
| เกม แอนิเมชัน และเสียง | ตัวละคร เส้นทางเดิน จังหวะภาพ เอฟเฟกต์ เสียง และประสิทธิภาพ | คนไข้เดินไปห้องยา เจ้าหน้าที่ประจำจุด |
| หน้าเว็บและการเรียนรู้ | การกดใช้งาน หน้าต่าง สมุด SOAP การเก็บร่างและส่งออก | คลิกเภสัชกรแล้วเปิดงานที่เกี่ยวข้อง |
| ข้อมูล ระบบหลังบ้าน และความปลอดภัย | โครงสร้างข้อมูล บัญชี สิทธิ์เข้าถึง ฐานข้อมูล และการเปลี่ยนข้อมูลอย่างปลอดภัย | รองรับหลายเคสและหลายผู้เรียน |
| ตรวจสอบคุณภาพ (QA) | ตรวจงานเทียบคำสั่ง ทดสอบกรณีปกติและข้อผิดพลาด ตรวจระบบเดิม | ตรวจว่าร่างไม่หาย ตัวละครไม่กระโดด และปิดเสียงได้ |
| เนื้อหาคลินิกและการสอน — เปิดเมื่อถึงระยะทำเคส | จัดเคสตามโครงสร้าง ตรวจความสอดคล้องและแหล่งอ้างอิง แจ้งจุดที่ต้องให้อาจารย์ตรวจ | นำเคสที่ผู้ใช้ส่งมาจัดเป็นภารกิจและเกณฑ์ประเมิน |

## วิธีสั่งงาน

ผู้ใช้บอกสิ่งที่ต้องการตามปกติ ไม่ต้องเลือกฝ่ายหรือแจกไฟล์เอง เช่น:

> เพิ่มระบบคิว ให้คนไข้รอหน้าห้องยาและเดินเข้าเมื่อถึงคิว

ผู้ประสานงานจะแบ่งงานตามความจำเป็น เช่น ฝ่ายเกมดูการรอและการเดิน ฝ่าย UX/UI ดูหมายเลขคิว ฝ่ายหน้าเว็บเชื่อมสถานะกับปุ่ม ฝ่ายข้อมูลเข้าร่วมเมื่อจำเป็นต้องเก็บคิวจริง และฝ่าย QA ตรวจคิวซ้ำ การเปลี่ยนจุดหมาย และผลต่อการทำงานเดิม ก่อนผู้ประสานงานรวมและเผยแพร่

แต่ละงานจะมีเจ้าของ ขอบเขตไฟล์ เงื่อนไขว่าทำเสร็จเมื่อใด และผลการทดสอบ งานที่พึ่งพากันทำตามลำดับ งานที่แยกกันได้จึงทำคู่ขนาน ไม่เปิดทุกฝ่ายพร้อมกันโดยไม่มีงานให้ทำ

## หลักการร่วมของโปรเจกต์

- ตอนนี้ให้ความสำคัญกับโครงเกม ฉาก ตัวละคร การใช้งาน และเสียงก่อน แล้วค่อยเพิ่มเคสจากผู้ใช้
- เจ้าหน้าที่ประจำจุด มีเฉพาะคนไข้ที่เดิน ระบบฉากแยกจากรายละเอียดเคส
- รักษาระบบเดิม คะแนน และข้อมูลร่าง ไม่รับรองว่าไม่มีบั๊กโดยไม่มีหลักฐาน
- ผู้ประสานงานรับผิดชอบผลรวม ไม่โยนภาระให้ผู้ใช้ต้องตามแต่ละฝ่ายเอง
- รายงานเฉพาะงานที่ทำจริงและตรวจจริง พร้อมระบุส่วนที่ยังไม่ได้ตรวจ

## ขอบเขตของระบบทีมนี้

นี่คือกติกาและวิธีประสาน AI ที่ใช้เมื่อทำงานกับโปรเจกต์ ไม่ใช่บริการ Agent ที่เปิดทำงานตลอดเวลาในเซิร์ฟเวอร์ เมื่อเครื่องมือรองรับ ผู้ประสานงานจะเปิดผู้ช่วย AI ตามงานที่ได้รับ หากไม่รองรับ จะทำหน้าที่เหล่านี้ตามลำดับและแจ้งตามจริง

ไฟล์ AGENTS.md เป็นคู่มือให้ Agent อ่านเมื่อเปิดโปรเจกต์ แต่ไม่สามารถบังคับเครื่องมืออื่นให้อ่านได้อัตโนมัติทุกระบบ และไม่ให้สิทธิ์ใหม่เหนือคำสั่งผู้ใช้หรือข้อกำหนดของแพลตฟอร์ม
